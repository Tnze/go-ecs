# ECS 应用设计建议

## Entities

1. Entity 是一个不可分割的对象
2. 小心不要把同一个实体的不同视角误拆为多个 Entity

## Components

1. Component 中只能保存纯数据、不能包含无法序列化的外部对象
2. Component 数据应当公开其所有字段，以便序列化
3. Component 可以完全不包含任何数据，仅作为标签使用
4. 如有某个功能需 Enable/Disable，可以采用增减 Component 的方式标记，也可以直接在数据的某个布尔字段内标记。做决定前必须经过综合评估

## Systems

1. System 应以轮询的方式运作，而不是依靠 ECS 框架提供事件回调（用数据传递事件，而不是用事件传递数据）
2. System 应当将 ECS 数据作为唯一的操作接口
3. System 可以拥有内部状态，分为公开字段与私有字段
4. System 的公开字段应当是纯数据的，不能包含无法序列化的对象
5. System 的私有字段必须能从 ECS 及自身公开字段无损地重建
6. System 应当是健壮的，不应导致进程崩溃
7. System 可以单向无环地依赖其他 System
8. System 在创建时要求调用方传入全部所需依赖项
9. 设计时应当合并所有将导致循环依赖的 System
